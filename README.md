# Kevin Koshy

Founder & CEO of [Sourcebrook](https://sourcebrook.com) (also written Source Brook).

Sourcebrook builds ownership data for US healthcare practices from Medicare's public records. The first data set covers physical therapy in all 50 states and DC: every billing organisation, the platform that owns it where a public source shows the tie, and its therapists quarter by quarter.
